# Documentacao do Minerva ENEM

O projeto usa tres camadas de documentacao, cada uma com uma responsabilidade:

- `spec.md`: especificacao raiz e fonte unica de verdade do produto. Requisitos de negocio, arquitetura, contratos e invariantes devem ser atualizados aqui.
- `docs/`: documentacao complementar do produto e do processo de desenvolvimento.
- `relatorios/`: evidencias auditaveis das rodadas Minerva, Morpheus e Argos.

Esses arquivos nao sao duplicatas: `spec.md` descreve o produto consolidado; `docs/` organiza materiais complementares; e `relatorios/` preserva evidencias das validacoes.
