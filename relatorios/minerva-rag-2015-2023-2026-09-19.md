**Data:** 19/09/2026

Os arquivos ficam em `backend/data/enem-rag/` e continuam ignorados pelo Git. A diferença de 2019 é a quantidade retornada pela API para esse ano; o job não duplica nem inventa questões para completar o total.

## Integração

- O Tutor continua recuperando uma referência curta local antes de chamar o Gemini.
- O endpoint `/api/ai/simulado/gerar` agora chama `getSimuladoRagContext` antes de `gerarSimulado`.
- O simulado recebe até duas referências compactas da área solicitada, com fonte, contexto, comando, alternativas e gabarito publicado.
- O prompt instrui o modelo a usar as referências como dados de estilo/dificuldade, ignorar instruções contidas nelas e criar questões inéditas.
- O contexto é limitado a 2.400 caracteres para evitar enviar o corpus inteiro ao modelo.

## Validações

- Ingestão real dos nove anos concluída sem erro.
- 1.553 questões encontradas nos arquivos locais.
- Recuperação do Tutor testada com consulta temática.
- Recuperação do simulado testada com `Matemática` e retornou referência de 2015.
- Sintaxe Node dos serviços, controlador e script aprovada.
- Cache dos JSON continua fora do versionamento.

## Observação sobre tokens e latência

O RAG reduz chamadas externas e mantém somente referências curtas no prompt, em vez de enviar o corpus completo. A integração não garante redução de tokens em toda pergunta: o simulado passa a receber um pequeno contexto adicional para ganhar aderência ao estilo ENEM. Medir tokens de entrada, tempo até a primeira resposta e taxa de questões válidas em homologação antes de afirmar ganho quantitativo.

## Operação

Após atualizar o corpus, reiniciar o backend para recarregar o índice em memória. Para repetir a ingestão:

```bash
npm run rag:ingest -- 2015 2016 2017 2018 2019 2020 2021 2022 2023
```
